How it Works

  • The Problem: Exact EMD under translation requires an expensive grid search.
  • The Approximation: We convert discrete points into blurred images.
  • The FFT Magic: Using the Convolution Theorem, we compute the overlap of these images across all translations at once.
  • The Result: The brightest pixel in the Cross-Correlation map indicates the $\Delta x, \Delta y$ that optimally aligns the sets.
